# 滆湖服务区（武汉方向）用户行为模式识别阶段总结

数据范围：`outputs/cleaned/gehu_wuhan_standard_user_orders.csv` 与 `outputs/abnormal/gehu_wuhan_abnormal_orders.csv`

目标边界：仅服务用户行为模式识别，不做需求预测、设备规划、站点运营优化或聚类建模训练。

## 一、本次所作工作

### 1. 明确用户行为识别的数据口径

围绕“用户行为模式识别”这一目标，先对清洗后的正常订单和异常订单进行字段梳理，明确哪些字段参与用户行为分析，哪些字段仅作为辅助说明。重点统一了用户主键、有效订单、异常订单、沉默用户和异常风险等口径，避免后续特征汇总和标签解释出现口径不一致。

其中，用户主键按 `用户编码 -> VIN码（清洗后） -> 手机号 -> 交易流水号` 的优先级生成，保证同一用户的订单尽可能归并到同一个识别对象下。

### 2. 构建订单级行为分析基础

在订单层面，将每笔订单加工成可分析的行为单元。处理内容包括充电时间特征、周末/夜间/跨日等时间行为，优惠与价格相关行为，以及异常订单、异常结束、零电量、超长充电等风险信号。

这一步的作用是把原始订单记录转为后续用户聚合可以直接使用的明细特征，而不是直接做用户结论。

### 3. 汇总用户级多维行为特征

在用户层面，按用户主键聚合订单级特征，形成用户行为宽表。特征覆盖用户活跃度、充电频次、消费价值、充电时段偏好、优惠和谷段偏好、站点/桩位使用偏好、异常订单占比等维度。

这一步是本阶段分析的核心基础，它把分散的订单行为压缩为每个用户一行的可识别行为画像。

### 4. 完成 RFM 分层和行为标签划分

基于用户级宽表，对用户进行 RFM 价值分层，并进一步划分价格敏感等级、站点偏好类型和异常风险等级。RFM 用于识别用户价值和活跃程度，价格敏感、站点偏好和异常风险用于补充用户行为模式解释。

本次已将价格敏感中的 `未知` 并入 `低价格敏感`，最终只保留 `高价格敏感`、`中价格敏感`、`低价格敏感` 三类，保证结果表和可视化图表口径一致。

### 5. 输出最终结果与重点图表

最后整合用户级宽表、RFM 分层和行为标签，输出可用于后续画像、聚类或群体识别的最终结果，并生成少量关键 SVG 图表用于展示主要现象。

本次需要重点保留和使用的最终产物如下：

| 产物 | 用途 |
| --- | --- |
| `final_user_behavior_profile.csv` | 最终用户行为特征宽表 |
| `final_user_behavior_labels.csv` | 用户标签结果表 |
| `user_behavior_rfm_segments.csv` | RFM 与行为分层结果 |
| `final_user_behavior_output_overview.csv` | 最终输出概览 |

## 二、重要现象与结论

### 1. 用户结构以低频、偶发型用户为主

本阶段最终识别用户数为 6836 人。RFM 结果显示，用户主要集中在“新近低频用户”和“一般用户”，低频低价值用户也占有一定规模，高价值活跃用户数量很少。

结论：该服务区用户更符合高速服务区场景下的路过型、偶发型充电特征，而不是稳定高频复购型用户结构。高价值活跃用户样本过少，不宜作为主体客群解读。展示该结论时可配合 `rfm_type_donut.svg` 或 `rfm_type_distribution.svg`。

### 2. 价格敏感不是主要行为差异来源

价格敏感等级整体以低价格敏感为主，高价格敏感和中价格敏感用户规模较小。

结论：优惠、谷段偏好等价格相关行为不是本批用户行为差异的主要来源。本次已将价格敏感中的 `未知` 并入 `低价格敏感`。在不同 RFM 类型内部仍存在少量高价格敏感用户，因此 `price_sensitivity_by_rfm_type.svg` 中部分 RFM 类型不是 100% 低价格敏感，这是正常的组内结构分布。展示该结论时可配合 `price_sensitivity_distribution.svg` 和 `price_sensitivity_by_rfm_type.svg`。

### 3. 站点偏好高度集中

站点偏好结果显示，用户主要表现为固定桩使用特征，多桩流动用户较少。

结论：这一现象可能与服务区充电站设备数量、订单发生位置集中、用户路过时选择可用桩有关。该标签适合用于识别用户对具体桩位的使用集中度，但不应直接解释为长期居住地或固定通勤行为。

### 4. 异常风险用户占比需要关注

异常风险等级整体以低风险用户为主，但仍存在一批高风险用户。分 RFM 类型观察，低频低价值用户中的高风险倾向更明显。

结论：高风险主要由异常订单占比、异常结束、零电量订单或超长充电等指标触发。低频低价值用户可作为异常行为筛查和用户行为质量识别的重点群体。展示该结论时可配合 `risk_level_donut.svg` 和 `risk_level_by_rfm_type_heatmap.svg`。

### 5. 后续可直接使用的核心结果

后续画像、聚类或群体识别建议优先使用：

| 文件 | 用途 |
| --- | --- |
| `final_user_behavior_profile.csv` | 建模或画像使用的用户级宽表 |
| `final_user_behavior_labels.csv` | 直接用于业务解读的用户标签结果 |
| `user_behavior_rfm_segments.csv` | RFM、价格敏感、站点偏好、风险分层结果 |

核心结论：本阶段已经完成从订单级行为单元到用户级特征宽表，再到 RFM 与行为标签结果的闭环输出。当前样本的主要用户模式是“新近低频 + 低价格敏感 + 固定桩使用 + 低风险为主，但存在一定比例高风险用户”。
